# Belegging rendement PWA

Persoonlijke, reclamevrije PWA voor het snel berekenen van beleggingsrendement.

## Bestanden

- `index.html` — de app
- `manifest.webmanifest` — PWA-instellingen
- `sw.js` — offline service worker
- `icons/` — app-iconen

De ingevoerde bedragen worden alleen lokaal in de browser/app opgeslagen via `localStorage`.
